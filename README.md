# ARC'TERIX "Climbing Day 2025" Competetion

## 概要

ARC'TERIX社協賛のクライミングイベント「Climbing Day 2025( https://arcteryx.jp/pages/climbing_day_at_ogikubo_20251129 )」に使用した課題管理・ランキングシステムです。参加者が課題を完登した記録を管理し、リアルタイムでポイント計算とランキング表示を行うWebアプリケーションです。

##  主機能

### 参加者向け機能
- **課題一覧表示**: 登録された全課題の閲覧
- **完登記録の送信**: 完登した課題を記録として送信
- **個人別ランキング表示**: カテゴリー別のリアルタイムランキング
- **QRコードアクセス**: 個人専用URLへの簡単アクセス

### 管理者向け機能
- **課題登録システム**: 課題番号、配点、画像の一括管理
- **参加者登録**: UUID自動生成による参加者管理
- **QRコード生成**: 個人URL用QRコードの自動生成

## 技術スタック

### バックエンド
- **Python 3.11.7**
- **Flask**: Webフレームワーク
- **PyMySQL**: MySQL データベース接続

### データベース
- **MySQL**: メインデータベース

  - `kadai`: 課題情報
  - `record`: 完登記録

### 画像処理
- **Pillow (PIL)**: 画像のトリミング、フィルター処理
- **qrcode**: QRコード生成

### フロントエンド
- HTML / CSS

## システム詳細

### 1. 動的ポイント計算
完登者数に応じてポイントを自動調整する仕組みを実装しました。

```python
point = int(record['point'] / senders_list[kid])
```

多くの参加者が完登した課題ほどポイントが低くなり、難易度の高い課題が高得点になる設計。

### 2. 画像処理パイプライン
アップロードされた画像を自動で加工する機能を実装しました。

- **アスペクト比調整**: 4:1の比率に自動クロップ
- **リサイズ処理**: 800x200pxに統一
- **モノクロ処理**: 完登済み課題の視覚的区別のため、彩度・明度を調整
- **チェックマーク合成**: 完登マークの自動追加

### 3. UUID ベースの個人URL
各参加者に一意のUUIDを付与し、個人専用のURLを生成。セキュアで管理しやすい設計を実現しました。

### 4. リアルタイムランキング
完登記録が送信されると即座にポイント計算が行われ、ランキングに反映されます。(同点の場合は同順位として表示)

## DB設計

### player テーブル
| カラム名 | 型 | 説明 |
|---------|-----|------|
| id | INT | 主キー |
| UUID | VARCHAR | 個人識別用UUID |
| name | VARCHAR | 参加者名 |
| category | VARCHAR | 参加カテゴリー |

### kadai テーブル
| カラム名 | 型 | 説明 |
|---------|-----|------|
| number | INT | 課題番号（主キー） |
| point | INT | 基礎配点 |
| img | VARCHAR | 画像パス |

### record テーブル
| カラム名 | 型 | 説明 |
|---------|-----|------|
| category | VARCHAR | カテゴリー |
| player_id | INT | 参加者ID |
| kadai_id | INT | 課題ID |
| rec | TINYINT | 完登フラグ |
